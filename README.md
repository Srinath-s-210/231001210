# Student Management System

## 📌 Problem Statement
This project implements a simple Student Management System using Python.  
The program stores and displays student details such as name and register number.

---

## ⚙️ Approach / Logic
- Used **Object-Oriented Programming (OOP)** concepts  
- Created a `Student` class  
- Used `__init__` constructor to initialize student details  
- Used **private variables** (`__name`, `__regno`) for data protection  
- Implemented a `display()` method to show student information  

---

## ▶️ How to Run
1. Install Python (version 3 or above)  
2. Open terminal / command prompt  
3. Navigate to project folder  
4. Run the program:
   ```bash
   python main.py
